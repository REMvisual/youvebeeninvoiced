## [1.0.0] - 2026-10-22

First public release.

### Added
- Invoices with line items, percent or fixed discount, optional add-on tax, and
  a withholding rate that shows the expected net after tax deducted at source.
- Six PDF templates (Classic, Modern, Minimal, Bold, Elegant, Compact), preset
  and custom accent colours, optional logo.
- Send by email: opens Gmail (or any email app) with recipients, subject, body
  and the PDF attached. Editable email template with placeholders.
- In-app PDF preview.
- Sent / Updated tracking with automatic revision numbers on resend.
- Mark paid with date and amount actually received.
- Clients with several named recipients each; autocomplete on invoices.
- Saved items catalogue; autocomplete fills description and price.
- CSV export (one file per invoice, one per line item).
- Export all data to a JSON backup and import it back (Settings > Data).
- Everything stored on the phone. No account, no internet permission.
